# Rapport d’audit des balises Wiki de capacités

Toutes les balises rencontrées dans le dataset des Warframes et des aptitudes Helminth ont été auditées :
- `<DT_VIRAL_COLOR>` → Icône officielle Viral (`ViralDamage.png`)
- `<DT_HEAT_COLOR>` / `<DT_FIRE_COLOR>` → Icône officielle Heat (`HeatDamage.png`)
- `<DT_FREEZE_COLOR>` → Icône officielle Cold (`ColdDamage.png`)
- `<DT_EXPLOSION_COLOR>` → Icône officielle Blast (`BlastDamage.png`)
- `<DT_RADIATION_COLOR>` / `<DT_RADIANT_COLOR>` → Icône officielle Radiation (`RadiationDamage.png`)
- `<DT_CORROSIVE_COLOR>` → Icône officielle Corrosive (`CorrosiveDamage.png`)
- `<DT_POISON_COLOR>` → Icône officielle Toxin (`ToxinDamage.png`)
- `<DT_ELECTRICITY_COLOR>` → Icône officielle Electricity (`ElectricityDamage.png`)
- `<DT_SLASH_COLOR>` → Icône officielle Slash (`SlashSymbol.png` / `SlashDamage.png`)
- `<DT_SENTIENT_COLOR>` → Icône officielle Void (`VoidDamage.png`)
- `<HEALTH>` → Icône officielle Health (`IconHealth.png`)
- `<ENERGY>` → Icône officielle Energy (`EnergyOrb.png`)
- `<AFFINITY_SHARE>` → Icône officielle Affinity (`Affinity.png`)

Aucune balise orpheline n’a été laissée de côté : l’ensemble des tags du jeu est converti en badges miniatures conformes aux standards officiels du Wiki Warframe.
