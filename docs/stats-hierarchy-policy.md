# Politique de hiérarchie des sources et statistiques Warframe

Ce document définit l'ordre de priorité appliqué par le Cephalon Codex pour garantir la fiabilité absolue des builds recommandés.

## Ordre de priorité des sources
1. **Statistiques en jeu / Captures / Vidéos validées** (ex. : captures de l'arsenal, builds de créateurs comme MHBlacky, PANDAAHH, TheKengineer, etc.) : **Priorité maximale** pour les valeurs finales réelles (Force, Portée, Durée, Efficacité, Santé, Armure, DPS effectif). Ce sont les mesures les plus fidèles aux conditions de jeu réelles.
2. **Wiki officiel Warframe et API publique** : Référence absolue pour les formules de calcul, les effets de mods, les arcanes, les éclats d'Archonte et les arbres Incarnon.
3. **Dataset normalisé du Builder** : Base de données locale garantissant la cohérence des sélections dans l'application.

## Application dans le chatbot
Le Cephalon Codex utilise désormais ces statistiques in-game comme étalon de référence pour valider ou ajuster les propositions de haut niveau (Endgame / Steel Path), tout en expliquant les compromis (coût en capacité, polarités, survie).
