# Vérification visuelle — Affectation rapide des reliques

Le simulateur Radshare reste lisible sur mobile après l’ajout de l’état de slot cible. Le sélecteur de joueur est conçu pour choisir Joueur 1 à Joueur 4, puis chaque carte de relique propose une action compacte d’affectation vers le slot choisi. L’état de raffinage du slot n’est pas modifié lors de l’affectation : seule l’identifiant de relique est remplacé, le calcul existant se met donc à jour avec le niveau de raffinage conservé.
