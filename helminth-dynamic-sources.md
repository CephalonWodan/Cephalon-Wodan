# Règles Helminth utilisées par le Set Builder

Source officielle consultée : [Helminth — Subsumable Ability Checklist](https://wiki.warframe.com/w/Helminth#Subsumable_Ability_Checklist).

Le Wiki indique qu’une configuration de Warframe ne peut remplacer qu’une seule capacité, et que les remplacements sont réversibles. Il précise également que les mods de **Force**, **Durée** et **Efficacité** affectent normalement les capacités Helminth ; la section de scaling liste les familles de mods de Force, Durée et Portée applicables. Le Builder conserve donc un seul remplacement Helminth par set, lié à un slot de capacité de 1 à 4.

Le Wiki précise aussi l’existence de restrictions pour les buffs de dégâts comme **Eclipse**, **Roar** et **Xata’s Whisper** sur certaines capacités natives. Le module actuel expose le choix de slot et affiche les restrictions générales dans l’interface ; les restrictions spécifiques pourront être enrichies dans une étape dédiée si une fiche complète par Warframe est demandée.

Les valeurs dynamiques affichées par le Builder suivent les pourcentages calculés à partir des mods, arcanes et éclats déjà actifs : Force, Durée, Portée et Efficacité. Les valeurs de base des aptitudes Helminth sont conservées séparément afin de ne pas confondre une valeur native et une valeur modifiée.
